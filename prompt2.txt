# 3. Use a REAL demo spatial dataset

For the next stage, do not rely solely on the previously created random synthetic `StereoExpData`.

Use the **SpatialData ecosystem's small mouse-liver spatial transcriptomics demo dataset** as the main development dataset.

The official example is documented here:

```text
https://spatialdata.scverse.org/en/latest/tutorials/notebooks/notebooks/examples/intro.html
```

The demo is useful because it contains multiple spatial data types, including concepts such as:

```text

segmentation
transcript points
cell/nucleus boundaries
AnnData expression data
spatial coordinates
metadata
```

Use it specifically because our viewer needs to handle multiple spatial layers rather than only a count matrix.

# 20. Keep performance in mind

The current demo is small.

The eventual Stereo-seq datasets may contain:

```text
100,000+
1,000,000+
10,000,000+
```

spatial bins.

Therefore do not build the viewer around:

```text
one DOM element per point
```

or:

```text
send entire matrix to browser
```

The architecture should eventually support:

```text
viewport filtering
lazy loading
chunking
downsampling
caching
LOD
Canvas/WebGL
tiled images
```

For now, implement only what is necessary for the demo, but keep these requirements in mind.
